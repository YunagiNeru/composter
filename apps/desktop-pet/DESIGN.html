01 / 判断

目的と状態

猫を起動し、PC状態、行動、設定、AIの元出力を同じ端末で確認する。

DEC-001

SOMの役割

承認済み
種別
決定
規範強度
必須
範囲
猫の固定行動選択

SOMは固定候補から行動IDを選ぶ。CPUの運動量、RAMの覚醒度、GPUの表示倍率、通信・ディスクの表現はアプリ側の制御で保つ。

理由と影響

モデルが誤った行動を選んでもPC状態の直接表現を失わない。安全制約で行動を変えた場合は、モデル要求と適用結果を別々に示す。

動作仕様

猫の全フレーム

猫は黒（#000000）と白（#ffffff）だけで表現する。描画元は64×64 RGBA・透明背景とし、表示倍率は最近傍法で変える。GPUは表示面積だけを変え、猫の体格はディスク容量から決める。

生成物

通常・眠気・歩行・走行・睡眠・鳴き・耳・撫で・食事・遊び・掘り・体格を含む50フレームをコードから生成する。1倍、2倍、4倍の代表ポーズと、全50フレームを行別に並べた2倍一覧を同梱する。

04 / 利用

起動と操作

作業ディレクトリと実行Pythonを固定して起動する。

  1. 起動

    Set-Location C:\work\composter\apps\desktop-pet
& ..\..\som-probe\.local\venv-desktop-pet\Scripts\python.exe -m desktop_pet

    猫を先に表示し、その後に別プロセスでNPUモデルを読み込む。右クリックの「AIの状態を見る」で実デバイス、3720、PLUGIN、PIDを確認する。

  2. 表示とふれあい

    猫を左クリックまたはなぞって撫でる。右クリックから「餌をあげる」「遊ぶ」「PCの状態を見る」「AIの状態を見る」「設定」「非表示」「終了」を選ぶ。トレイから表示を戻すか終了する。

  3. 移動

    右クリックから「移動モード」を選び、左または右ドラッグする。Escで解除する。画面やDPI変更時は表示可能領域へ位置を戻す。

  4. 架空状態による確認

    Set-Location C:\work\composter\apps\desktop-pet
& ..\..\som-probe\.local\venv-desktop-pet\Scripts\python.exe -m desktop_pet --demo-metrics

    6秒ごとに架空状態を切り替える。実測値ではなく、このモードは設定を保存しない。

白黒猫への置換（2026-10-27）

旧茶トラの輪郭・顔・体形を置換した。短い足、大きな頭、巻いた尻尾、座る姿と四足歩行を描き分け、全状態で黒・白・透明の3種類の画素だけを使う。暗い壁紙向けに1ピクセルの白縁を付ける。NPU、センサー、行動ID、設定の契約は変更していない。

追加の形状指定に合わせ、鼻の白い点と通常目の黒い瞳孔を削除した。通常目は白一色とし、全フレームの足先の横への張り出しを取り除き、縦に伸びてU字に丸く閉じる短い足へ揃えた。通常目・眠気を実アプリで撮影して目視し、全50フレームの一覧と関連27テストで再確認した。追加の画面証拠は som-probe/.local/cat-deformed-20261027/ に保存する。

評価件数は確認時点の情報である。両作品の公開プレビューを目視し、比率と動きの構成を参考にした。画像の転載・トレース・パッケージへの取り込みは行わず、既存のQt描画処理で新たに描いた。外部画像生成サービスや追加依存は使っていない。

全50フレームの一覧、白背景・暗背景、実アプリの眠気・撫で反応・食事を目視した。関連27テストで白黒限定、透明な外周、64×64 RGBA、最近傍拡大、保存PNGと描画元の一致を確認した。実画面確認は python.exe -m desktop_pet --demo-metrics --no-ai で実施したため、この記録はNPU再検証を示さない。画面証拠はローカルの som-probe/.local/black-cat-20261027/ に保存する。デザインの好みを自動テストで合格扱いにはしない。

実機プロセス計測

Run 20261027-desktop-pet-final。架空状態モードで推論周期が続く中、利用者操作なしの60秒を記録した。Get-ProcessのWorkingSet64、PrivateMemorySize64（現Commit Charge）、PeakWorkingSet64、PeakPagedMemorySize64（ピークCommit Charge相当）、CPUを別々に保存した。UIはWorking Set 172.5→172.8 MB、Commit Charge 91.9→92.0 MB、起動以来のPeak Working Set 175.0 MB、PeakPagedMemorySize 94.0 MB。NPUワーカーはWorking Set 1,492.1→1,492.3 MB、Commit Charge 1,460.1→1,460.1 MB、起動以来のPeak Working Set 2,120.4 MB、PeakPagedMemorySize 1,460.3 MB。60秒間のCPU時間増加はUI 1.126秒、ワーカー0.031秒。ワーカーは1GiBのWorking Set目安を超える。採取開始は起動後約4分であり、起動時ピークの発生時刻やロード段階別の値は計測していない。

この確認は日本語品質、低資源PC対応、複数DPIの実機網羅、配布準備を保証しない。SOMの行動品質は未確定で、安全制約が要求を変更する場合がある。

透明領域のクリック透過、ドラッグ後の配置保持、トレイ復帰、モニター切断・DPI変更、長時間待機後の再表示は実機で網羅していない。ディスク稼働率は選択ボリューム別でなく全体値。

センサー制約

GPU利用率はNVIDIA NVMLのみ。未対応GPUでは未取得とする。PDHが利用できない場合もディスク稼働率は未取得。容量対象と稼働率の範囲をPC状態画面で分けて表示する。

インストーラー、自動起動、他のペット、SOM学習、モデル変更、GPU実行は含まない。ソース、モデル、IR、キャッシュ、venvは別の復旧単位として保つ。
